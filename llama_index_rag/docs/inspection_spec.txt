
服务器巡检规范

巡检频率：
  - 生产环境：每天执行一次全量巡检
  - 测试环境：每周执行一次基础巡检
  - 重大变更后：立即执行全量巡检

巡检项目清单：

1. 系统资源
  - CPU 使用率：告警阈值 85%，严重阈值 95%
  - 内存使用率：告警阈值 80%，严重阈值 90%
  - 磁盘使用率：告警阈值 75%，严重阈值 85%

2. 进程检查
  - 检查关键进程是否存活
  - 检查僵尸进程数量（超过10个告警）

3. 网络检查
  - 检查网络连通性
  - 检查 TIME_WAIT 连接数（超过5000告警）

4. 安全检查
  - 检查 SSH 登录失败次数（超过100次/小时告警）
  - 检查开放端口变化
  - 检查高危漏洞补丁状态

巡检报告：
  每次巡检完成后自动生成报告
  报告包含：健康评分、问题列表、处理建议
